# API para Gerenciamento de Tarefas

API REST desenvolvida com Spring Boot para gerenciamento de tarefas. Permite criar, consultar, listar, atualizar e remover tarefas, com validação dos dados de entrada e persistência em banco de dados com PostgreSQL.

O projeto segue a arquitetura em camadas (controller, service, repository e model) e foi criado para praticar o desenvolvimento backend com Java e Spring Boot.
